# DSH ClinePass

Плагин ClinePass для DeepSeek Harness. Его ведут в этом репозитории:
[xiangnan0811/dsh-clinepass](https://github.com/xiangnan0811/dsh-clinepass).

[English](README.md) · [中文说明](README.zh.md)

Пространство настроек — `dsh-clinebot`, id провайдера — `clinebot`, префикс
маршрутов — `/dsh-clinebot`. Не ставьте в тот же профиль другой плагин,
который тоже регистрирует провайдера `clinebot`: оба пишут
`llm-pi-ai.providers.clinebot`.

Имя пакета — `dsh-clinepass`. `private: true` блокирует `npm publish`.

## Установка из репозитория

DeepSeek Harness ставит плагины через pnpm. Достаточно адреса GitHub:

```sh
dsh plugin --profile web add github:xiangnan0811/dsh-clinepass
```

Перезапустите `dsh`. **ClineBot** есть на боковой панели настроек. Страница **Плагины** тоже открывает его из строки `dsh-clinebot` внутри `dsh-clinepass`. Пункт «Встроенные плагины» в настройках только показывает список и больше не содержит эту карточку.

Боковая витрина (`dsh-market`) не требует npm. Установка оттуда вызывает
`dsh plugin --profile web add github:владелец/репозиторий`. `npm publish` нужен только для
`dsh plugin --profile web add <имя-в-npm>`.

Этот репозиторий не является форком GitHub. Для каталога нужны тема
`dsh-plugin` на странице About и `cordis.patch.yml` в корне. Индекс
запускается около 06:00 и проверяет, что это плагин DSH. Другой путь —
issue в [2BingLing/dsh-market](https://github.com/2BingLing/dsh-market).

Не задавайте `CLINEBOT_API_KEY` в оболочке, из которой запускается `dsh`.
DSH считает переменную источником только для чтения и отклоняет сохранение
ключа со страницы настроек. Ключ сохраняется в карточке плагина. Браузер
вызывает `http://127.0.0.1:<порт>/dsh-clinebot/...` у локального DSH. Плагин
затем вызывает `baseUrl`. Используйте `https://api.cline.bot/api/v1`.

## Страница настроек

- Адрес API и ключ ClinePass.
- Окна 5 часов, недели и месяца из `GET /users/me/plan/usage-limits`:
  процент, шкала и дата сброса. Аккаунт, тариф и время последнего запроса —
  отдельные строки. Адрес почты по умолчанию скрыт и открывается кнопкой. Время отмены тарифа — отдельная
  строка. Если сохранено больше одного ключа, остальные аккаунты показаны
  тремя процентами. Этот список не меняет выбор аккаунта после лимита.
- Выбранные модели регистрируются в DSH. Потолок вывода не отправляется как
  `max_tokens`. Отправляется бюджет запроса. Бюджет по умолчанию — 65536.
- Поиск, быстрый выбор, фильтр проверенного тарифа, пакетные параметры и формы
  пользовательских моделей. Явно пустой выбор не регистрирует модели. Отдельные
  настройки важнее пакетных; восстановление возможностей не меняет бюджет запроса.
- Проверка ключа без сохранения и поиск по запросу в известных файлах Cline CLI,
  VS Code, Cursor и переменных окружения Cline. Список содержит маски; серверные
  идентификаторы для импорта действуют пять минут. Зашифрованные секреты редактора
  могут быть недоступны.
- Модель для проверки связи выбирается в карточке. Для Muse Spark
  отправляются `reasoning_effort: low` и предел 1024, чтобы рассуждение не
  съело короткий ответ.
- Статистика профиля сохраняет результаты запросов, попытки, задержки и
  сообщённые счётчики токенов. Есть фильтры даты UTC, модели и аккаунта, CSV
  и сброс. `/cline stats` и `/cline telemetry` показывают те же итоги.
  Тексты запросов и значения ключей не сохраняются.
- Кнопка квоты на боковой панели открывает нативное окно с квотами, статистикой
  и полной конфигурацией, доступной на узком экране. Отсутствующие данные и время
  сброса остаются неизвестными. Панель квоты и блок ввода включены по умолчанию,
  но отключаются отдельно.
- Блок ввода показывает только ответы/попытки ClinePass текущей сессии, исключая
  других провайдеров. Оценка стоимости требует явно заданных ставок модели за
  миллион входных/выходных токенов. Валюта по умолчанию USD — только единица,
  без конвертации. Нет ставки или полного usage — нет расчёта. Кэш учитывается
  по входной ставке, рассуждение уже входит в вывод.
- Потоковая диагностика измеряет первый текст/рассуждение/вызов инструмента и
  полное время, допускает отмену, ограничена 1024 выходными токенами и 30 секундами.
  Она учитывается в статистике профиля, отдельно от ответов сессии.
  `/cline ping <model>` и `/cline ping default` запускают диагностику; без аргумента
  `/cline ping` проверяет доступность API. `/cline account` показывает аккаунты,
  `/cline use <name>` закрепляет аккаунт, `/cline use auto` возвращает авторежим.
- На той же карточке можно сохранить дополнительный `CLINEBOT_API_KEY_*`.
  Имя в пуле записывается до секрета. Если секрет не сохранился, новое имя
  убирается из пула. Ответ HTTP 429 или 402 на следующем ходе DSH переключает
  активный ключ на следующий сохранённый аккаунт. Переключение, этот поворот,
  новый адрес API, новое имя основного ключа или замена активного ключа
  сбрасывают список моделей прошлого плана до следующего успешного чтения.
  Замена активного ключа также удаляет сохранённый кэш плана, поэтому старый
  список не восстанавливается с диска. Уже начатое чтение плана не может
  вернуть этот список. `/cline` печатает обычный текст.

`GET /api/v1/models` на api.cline.bot отвечает 404. С ключом список читается
из `GET /users/me/plan`. `cline-pass/deepseek-v4.1-flash` — обычный id
ClinePass и модель проверки связи по умолчанию.

Текущий кандидат предназначен для DeepSeek Harness `0.2.1-rc.2` (`next` на 2026-10-19). Проверка `0.1.7-rc.2` относится к предыдущим версиям. Пункт в настройках —
`settings.section` `dsh-clinebot`. Та же страница зарегистрирована как
`plugins.row.config` с ключом `dsh-clinepass#dsh-clinebot`.

Если хост предоставляет `connection.requestRejection`, все маршруты
`/dsh-clinebot/*`, включая чтение и проверку обновлений, требуют аутентификации
DSH. Откройте адрес, напечатанный `dsh web`. Без аутентификации ответ — 401,
при отказе проверки хоста или источника — 403. Запись настроек также сохраняет
проверку источника.

## Конфигурация

```yaml
dsh-clinebot:
  enabled: true
  baseUrl: https://api.cline.bot/api/v1
  apiKeyEnv: CLINEBOT_API_KEY
  defaultModel: cline-pass/deepseek-v4.1-flash
  selectionKind: all-except-disabled
  timeoutMs: 15000
  smokeTimeoutMs: 25000
```

| Поле | По умолчанию | Назначение |
| --- | --- | --- |
| `baseUrl` | `https://api.cline.bot/api/v1` | API, который вызывает плагин |
| `apiKeyEnv` | `CLINEBOT_API_KEY` | Имя учётных данных |
| `defaultModel` | `cline-pass/deepseek-v4.1-flash` | Проверка связи и модель провайдера |
| `selectionKind` | `all-except-disabled` | Пустой `disabledModels` регистрирует каталог |
| `planFilterEnabled` | `false` | Пересечение ручного выбора с проверенным тарифом; отсутствие данных не очищает выбор |
| `batchModelDefaults` | Наследование | Контекст, возможности вывода и бюджет, ниже отдельных настроек |
| `timeoutMs` | `15000` | Запросы тарифа и квоты |
| `smokeTimeoutMs` | `25000` | Проверка связи |
| `webSearchEnabled` | `false` | Регистрация провайдера поиска `clinebot` без изменения глобального выбора |
| `searchTimeoutMs` | `15000` | Срок поиска, включая тело ответа |

В «Настройки → Модели» попадают отмеченные модели. Контекст, потолок вывода,
бюджет запроса, ввод и рассуждение правятся по модели. Пустое поле наследует
сначала пакетные параметры, затем каталог. Правки страницы моделей DSH сохраняются
в `hostModelOverrides` при скрытии моделей и перезапуске. Явное изменение или
восстановление поля в карточке очищает соответствующую правку. Уровень рассуждения
по умолчанию применяется до фиксации нативного запроса; явный выбор, включая Off,
важнее. На next только `clinebot` передаётся адаптеру ClinePass для наблюдения
фактических данных usage. Параметры доступны в «Настройки → Модели».

`proxyEnabled` по умолчанию выключен. Прокси слушает только loopback и использует
отдельный секрет в DSH credentials. Маршрут модели важнее ручного выбора аккаунта,
затем привязки сессии и стратегии `least-used` или `round-robin`. Повтор на другом
аккаунте разрешён только до первого вывода модели. Отключение восстанавливает
адрес, аккаунт и исходные параметры повторов и тайм-аутов. Сроки подключения,
первого вывода и JSON — 15 с, простоя потока — 30 с, всего — 300 с;
полный запрос ограничен 32 MiB. Лимиты изображений задаются отдельно.
`historyImageOffload` выключен по умолчанию, `historyImagesToKeep` равен 2.
Выгрузка требует нативного плагина хоста, записывает решение в журнал сессии и
сохраняет исходные вложения. Оставшаяся работа описана в
[плане синхронизации](docs/maintenance/UPSTREAM_SYNC_PLAN.md).

Файл статистики: `<каталог текущего профиля>/clinepass/stats.json`. Атомарная
замена и блокировка хоста защищают параллельную запись. Итоги по дате, модели и
аккаунту сохраняются; подробности — только для последних 100 запросов. Повтор
прокси не увеличивает число логических запросов. Отсутствующий usage неизвестен.
Итоги запросов относятся к последнему аккаунту; попытки сохраняют фактический
аккаунт. Строки CSV `scope=request|attempt` нельзя складывать как число запросов.
Кэш отделён от обычного ввода, рассуждение уже включено в вывод. Указывается доля
измеренных запросов; задержки — средние, без TTFT для не потоковой проверки.
Ошибка записи видна, но не прерывает модель; новые данные остаются в памяти.
Сброс очищает статистику всего профиля, сохраняя аккаунты и модели; повреждённый
файл сначала архивируется. Старые измерения не восстанавливаются расчётом.

Нативный поиск использует активный аккаунт и `POST /alpha/web-search` по адресу
`baseUrl`. После включения выберите `clinebot` в настройках поиска хоста.
Другие провайдеры поиска и загрузки сохраняются. Запрос ограничен 10 результатами
(по умолчанию 5). Пустой результат отличается от ошибок HTTP, ключа, формата,
тайм-аута и отмены. Нет скрытого перехода на другой сайт или смены аккаунта.
Отключение и выгрузка снимают регистрацию и отменяют текущие поиски.
Проверены изолированный next и локальная имитация; реальный канал ещё не проверен.

Обновления доступны в **Плагины → ClinePass updates**. Кнопка в настройках
открывает карточку пакета; вернитесь к списку плагинов и выберите эту вкладку.
Цель GitHub закреплена за проверенным коммитом этого репозитория. Для локальной
или registry-установки цель выбирается явно; локальное обновление принимает
абсолютный путь к `.tgz`/`.tar.gz`, созданному `npm pack`. Проверку, установку,
блокировку профиля, отмену и результат выполняет хост. Аккаунты, модели и
статистика сохраняются; фоновой установки нет.

Запущенная и установленная версии различаются даже при одинаковом номере.
Одинаковый путь архива или неизвестный Git-коммит не доказывает совпадение кода.
Выполните предложенный перезапуск/обновление страницы и проверьте снова. Архив
читается без распаковки: до 16 MiB сжатых данных, 64 MiB записей и 256 KiB
манифеста. `GET /dsh-clinebot/update` только проверяет цель; установка идёт через
нативное окно, прежняя HTTP-команда установки отвечает 405.

## Разработка

```sh
npm run build:client
npm test
```

`npm test` проверяет соответствие `lib/client.js` исходникам без перезаписи,
проверяет неопределённые имена и запускает тесты. `npm pack` собирает
локальный архив. Без установки с GitHub: `dsh plugin --profile web add ./<файл>.tgz`.
