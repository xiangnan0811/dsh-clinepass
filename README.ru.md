# DSH ClinePass

Плагин ClinePass для DeepSeek Harness. Его ведут в этом репозитории:
[xiangnan0811/dsh-clinepass](https://github.com/xiangnan0811/dsh-clinepass).

[English](README.md) · [中文说明](README.zh.md)

Пространство настроек — `dsh-clinebot`, id провайдера — `clinebot`, префикс
маршрутов — `/dsh-clinebot`. Не ставьте в тот же профиль другой плагин,
который тоже регистрирует провайдера `clinebot`: оба пишут
`llm-pi-ai.providers.clinebot`.

Имя пакета — `dsh-clinepass`. `private: true` блокирует `npm publish`.

## Установка из репозитория

Версия `0.8.0` требует DeepSeek Harness `^0.2.1-rc.2`.

DeepSeek Harness ставит плагины через pnpm. Достаточно адреса GitHub:

```sh
dsh plugin --profile web add github:xiangnan0811/dsh-clinepass
```

Перезапустите `dsh`. **ClineBot** есть на боковой панели настроек. Страница **Плагины** тоже открывает его из строки `dsh-clinebot` внутри `dsh-clinepass`. Пункт «Встроенные плагины» в настройках только показывает список и больше не содержит эту карточку.

Боковая витрина (`dsh-market`) не требует npm. Установка оттуда вызывает
`dsh plugin --profile web add github:владелец/репозиторий`. `npm publish` нужен только для
`dsh plugin --profile web add <имя-в-npm>`.

Этот репозиторий не является форком GitHub. Для каталога нужны тема
`dsh-plugin` на странице About и `cordis.patch.yml` в корне. Индекс
запускается около 06:00 и проверяет, что это плагин DSH. Другой путь —
issue в [2BingLing/dsh-market](https://github.com/2BingLing/dsh-market).

Не задавайте `CLINEBOT_API_KEY` в оболочке, из которой запускается `dsh`.
DSH считает переменную источником только для чтения и отклоняет сохранение
ключа со страницы настроек. Ключ сохраняется в карточке плагина. Браузер
вызывает `http://127.0.0.1:<порт>/dsh-clinebot/...` у локального DSH. Плагин
затем вызывает `baseUrl`. Используйте `https://api.cline.bot/api/v1`.

## Страница настроек

- Адрес API и ключ ClinePass.
- Окна 5 часов, недели и месяца из `GET /users/me/plan/usage-limits`:
  процент, шкала и дата сброса. Аккаунт, тариф и время последнего запроса —
  отдельные строки. Адрес почты по умолчанию скрыт и открывается кнопкой. Время отмены тарифа — отдельная
  строка. Если сохранено больше одного ключа, остальные аккаунты показаны
  тремя процентами. Этот список не меняет выбор аккаунта после лимита.
- Выбранные модели регистрируются в DSH. Потолок вывода не отправляется как
  `max_tokens`. Отправляется бюджет запроса. Бюджет по умолчанию — 65536.
- Поиск, быстрый выбор, фильтр проверенного тарифа, пакетные параметры и формы
  пользовательских моделей. Явно пустой выбор не регистрирует модели. Отдельные
  настройки важнее пакетных; восстановление возможностей не меняет бюджет запроса.
- Проверка ключа без сохранения и поиск по запросу в известных файлах Cline CLI,
  VS Code, Cursor и переменных окружения Cline. Список содержит маски; серверные
  идентификаторы для импорта действуют пять минут. Зашифрованные секреты редактора
  могут быть недоступны.
- Модель для проверки связи выбирается в карточке. Для Muse Spark
  отправляются `reasoning_effort: low` и предел 1024, чтобы рассуждение не
  съело короткий ответ.
- Статистика профиля сохраняет результаты запросов, попытки, задержки и
  сообщённые счётчики токенов. Есть фильтры даты UTC, модели и аккаунта, CSV
  и сброс. `/cline stats` и `/cline telemetry` показывают те же итоги.
  Тексты запросов и значения ключей не сохраняются.
- Кнопка квоты на боковой панели открывает нативное окно с квотами, статистикой
  и полной конфигурацией, доступной на узком экране. Отсутствующие данные и время
  сброса остаются неизвестными. Панель квоты и блок ввода включены по умолчанию,
  но отключаются отдельно.
- Блок ввода показывает только ответы/попытки ClinePass текущей сессии, исключая
  других провайдеров. Стоимость считается за миллион токенов отдельно для входа
  без кэша, выхода, чтения и записи кэша по ручной ставке, привязанной справочной
  цене или автоматически найденной цене `models.dev` в USD (в этом порядке).
  Валюта по умолчанию USD, без конвертации; другие валюты требуют ручных ставок.
  Нет цены кэша — берётся цена входа; несообщённые счётчики считаются нулём,
  модели без цены не учитываются. Подписка не тарифицирует запросы, это лишь ориентир. Запись кэша означает создание
  кэша промпта; рассуждение уже входит в вывод. Это справка по текущим ставкам,
  а не исторический счёт.
- Противоречивые счётчики токенов не участвуют в измерениях и расчёте стоимости;
  ответ модели и результат запроса сохраняются. Кэш проекции сессии пересчитывается
  из журнала по новым правилам; отсутствующие исторические данные не восстанавливаются.
- Потоковая диагностика измеряет первый текст/рассуждение/вызов инструмента и
  полное время, допускает отмену, ограничена 1024 выходными токенами и 30 секундами.
  Она учитывается в статистике профиля, отдельно от ответов сессии.
  `/cline ping <model>` и `/cline ping default` запускают диагностику; без аргумента
  `/cline ping` проверяет доступность API. `/cline account` показывает аккаунты,
  `/cline use <name>` закрепляет аккаунт, `/cline use auto` возвращает авторежим.
- На той же карточке можно сохранить дополнительный `CLINEBOT_API_KEY_*`.
  Имя в пуле записывается до секрета. Если секрет не сохранился, новое имя
  убирается из пула. HTTP 429 или подтверждённое исчерпание квоты аккаунта при прямом вызове
  переключает аккаунт для последующих запросов. HTTP 402 означает нехватку средств для этой модели
  и не меняет глобально активный аккаунт. Переключение, этот поворот,
  новый адрес API, новое имя основного ключа или замена активного ключа
  сбрасывают список моделей прошлого плана до следующего успешного чтения.
  Замена активного ключа также удаляет сохранённый кэш плана, поэтому старый
  список не восстанавливается с диска. Уже начатое чтение плана не может
  вернуть этот список. `/cline` печатает обычный текст.

На 2026-10-26 доступны публичные `/ai/cline/recommended-models` (модели
ClinePass), `/ai/cline/models` (имена и справочные параметры) и `/models`
(резервный список ID). Синхронизация тарифа отдельно читает `/users/me/plan`.
Модель проверки связи по умолчанию — `cline-pass/deepseek-v4.1-flash`.

Текущий выбор включает GLM 5.3 / 5.3 Flash, Kimi K3.1 Pro, MiniMax M3.1 Flash,
MiMo V2.6 Flash / Pro, Qwen 3.8 Max, DeepSeek V4.1 Flash (и 1017),
DeepSeek V4 Pro и Muse Spark 1.3 Contributor. Старые поколения остаются
доступны для явного выбора; сохранённые ID, бюджеты и ограничения провайдера
не переписываются. В режиме `all-except-disabled` список `explicitModels`
также хранит явно включённые старые модели.

В разделе пользовательских моделей можно загрузить список из API, найти модель
и заполнить имя, контекст, предел вывода и поддержку изображений. Обычные API ID
показаны отдельно: они не относятся к подписке ClinePass. Ключ отправляется
только настроенному API. Ручной ввод требует лишь ID; остальные поля необязательны.
Неизвестные возможности не угадываются. Бюджет запроса не превышает 65536 и
снижается до меньшего опубликованного предела. Сохранение включает модель,
но проверенный фильтр тарифа продолжает действовать. Пользовательская запись
сохраняется при смене аккаунта. Загрузка списка не выполняет генерацию и не
подтверждает доступ аккаунта или реальные ограничения канала.

Версия `0.8.0` предназначена для DeepSeek Harness `0.2.1-rc.2` (`next` на 2026-10-19). Проверка `0.1.7-rc.2` относится к предыдущим версиям. Пункт в настройках —
`settings.section` `dsh-clinebot`. Та же страница зарегистрирована как
`plugins.row.config` с ключом `dsh-clinepass#dsh-clinebot`.

Если хост предоставляет `connection.requestRejection`, все маршруты
`/dsh-clinebot/*`, включая чтение и проверку обновлений, требуют аутентификации
DSH. Откройте адрес, напечатанный `dsh web`. Без аутентификации ответ — 401,
при отказе проверки хоста или источника — 403. Запись настроек также сохраняет
проверку источника.

Версия `0.8.0` также проверена на изолированных Web и прямом headless
DSH `0.2.1-rc.3` с локальным шлюзом. Для headless нужно включить сервис
`credentials` (`disabled: false`) в patch профиля и выбрать `clinebot` с включённой
моделью в `agent-default-model`; ключ можно передать через окружение. По умолчанию
headless отключает этот сервис. Интеграция TUI отложена: в официальном хосте нет
проверенного потребителя `tuiSettingsSections`. Запись настроек требует Origin
или Referer; заголовок пересланного хоста доверен только loopback-прокси.

## Конфигурация

Синхронизация каталога начинается примерно через 0,5 с; при необходимости повторяется
через 3 и 15 с. Затем ежечасная проверка обновляет данные старше шести часов. Ручная
синхронизация использует тот же путь записи и время успешного обновления. Сбой сохраняет
достоверные данные; выключение и выгрузка отменяют чтение и поздние записи. Обычный опрос
квоты не загружает каталог. Кэш v4 изолирован по адресу API, аккаунту и отпечатку ключа;
старые версии перечитываются. Ошибка сохранения кэша видна как предупреждение, настройки
и вызовы моделей остаются доступны.

FREE и фильтр используют только точные ID из явного списка `free` рекомендательного
API шлюза (проверено 2026-10-29). Название и нулевая справочная цена не доказывают
бесплатность; права аккаунта и фактические вызовы проверяются отдельно. Датированные
модели используют точные ID и метаданные своей версии. ID поставщика не превращается
в Pass ID; каталог не расширяет состав тарифа и не импортирует модели автоматически.

В прокси HTTP 402 блокирует только пару аккаунт–модель на пять минут; до первого
вывода можно попробовать другой аккаунт. Другие модели того же аккаунта доступны.
Восстановление поддерживает модель; API только с аккаунтом очищает все его блокировки.
Прямые вызовы и диагностика не меняют глобальный аккаунт при 402. HTTP 413 и известные
ошибки размера запроса не повторяются и не переключают аккаунт: сократите сообщения,
изображения или создайте новый сеанс. Переполнение контекста классифицируется отдельно.
Новая статистика различает нехватку средств, лимит частоты и слишком большой запрос;
старые агрегаты не пересчитываются.

```yaml
dsh-clinebot:
  enabled: true
  baseUrl: https://api.cline.bot/api/v1
  apiKeyEnv: CLINEBOT_API_KEY
  defaultModel: cline-pass/deepseek-v4.1-flash
  selectionKind: all-except-disabled
  timeoutMs: 15000
  smokeTimeoutMs: 25000
```

| Поле | По умолчанию | Назначение |
| --- | --- | --- |
| `baseUrl` | `https://api.cline.bot/api/v1` | API, который вызывает плагин |
| `apiKeyEnv` | `CLINEBOT_API_KEY` | Имя учётных данных |
| `defaultModel` | `cline-pass/deepseek-v4.1-flash` | Проверка связи и модель провайдера |
| `selectionKind` | `all-except-disabled` | Текущие модели и явно выбранные старые, кроме `disabledModels`; явный режим использует только `explicitModels` |
| `planFilterEnabled` | `false` | Пересечение ручного выбора с проверенным тарифом; отсутствие данных не очищает выбор |
| `batchModelDefaults` | Наследование | Контекст, возможности вывода и бюджет, ниже отдельных настроек |
| `upstreamPins` | `[]` | Закрепление backend-провайдера ClinePass для каждой модели, отдельно от аккаунта |
| `timeoutMs` | `15000` | Запросы тарифа и квоты |
| `smokeTimeoutMs` | `25000` | Проверка связи |
| `webSearchEnabled` | `false` | Регистрация провайдера поиска `clinebot` без изменения глобального выбора |
| `searchTimeoutMs` | `15000` | Срок поиска, включая тело ответа |
| `statsRetentionDays` | `95` | Хранение минутных агрегатов: 0–3650 дней; 0 без ограничения, дневные итоги сохраняются |
| `quotaForecastEnabled` | `false` | Оценка темпа расхода квоты по сопоставимым замерам |
| `priceAutoSync` | `false` | Обновление справочных цен при синхронизации моделей, не чаще раза в шесть часов |
| `priceBindings` | `[]` | Явная привязка `{model, provider, sourceModel}`; ручные `costRates` имеют приоритет |
| `dailyBudget`, `monthlyBudget` | `0` | Локальные оценки расходов за сутки/месяц UTC в `costCurrency`; 0 отключает лимит |

Статистика дополняется границами P50/P95, тепловой картой по текущему смещению
UTC браузера, минутными интервалами с исключённой правой границей, фильтром ошибок
и экспортом JSON. Старые дневные итоги сохраняются без выдуманных новых замеров.
Все фильтры (период, модель, аккаунт, только ошибки) собраны в одной панели и
применяются сразу; карточка показывает состав токенов с долей попаданий в кэш,
справочную стоимость и разбивку по дате, модели и аккаунту. Поля, сообщённые
менее чем 95% запросов, помечаются.
Минутные фильтры охватывают только сохранённую детализацию. История хранит последние
200 событий маршрутизации, охлаждения, восстановления и смены аккаунта независимо
от сброса статистики. Дополнительный аккаунт можно переименовать или очистить его
сохранённый ключ, сохранив запись и закрепления; ключ окружения удаляется у источника.

Справочные цены `models.dev` в USD подбираются автоматически по имени модели
(сначала запись ClinePass, затем официальный вендор, затем прочие; суффикс `-MMDD`
пробуется без даты). Явная привязка провайдера и модели важнее, ручная строка
важнее всего. Бюджет использует ту же справочную оценку.
Кэш `clinepass/prices.json` принадлежит профилю, при ошибке обновления сохраняется
последний успешный каталог. Другие валюты требуют ручных ставок; конвертации нет.
Включённый бюджет блокирует новый вызов только при достижении лимита; нет цены
или данных — считается нулём.
Выполняющиеся запросы могут превысить лимит, сброс статистики сбрасывает расходы,
смена валюты переобозначает ручные ставки и лимиты. Это не счёт и не квота подписки.
Команды `/cline cost` и `/cline budget` показывают те же оценки. Прогноз квоты
по умолчанию выключен; ошибки, смена аккаунта и сброс окна очищают его.

В «Настройки → Модели» попадают отмеченные модели. Контекст, потолок вывода,
бюджет запроса, ввод и рассуждение правятся по модели. Пустое поле наследует
сначала пакетные параметры, затем каталог. Правки страницы моделей DSH сохраняются
в `hostModelOverrides` при скрытии моделей и перезапуске. Явное изменение или
восстановление поля в карточке очищает соответствующую правку. Уровень рассуждения
по умолчанию применяется до фиксации нативного запроса; явный выбор, включая Off,
важнее. На next только `clinebot` передаётся адаптеру ClinePass для наблюдения
фактических данных usage. Параметры доступны в «Настройки → Модели».

В отдельном разделе настроек **Pin upstream provider** выберите модель и
провайдера, например `deepseek` (редактор модели сохраняет тот же доступ), и
сохраните. Пустое значение или **Use automatic routing** снимает ограничение.
После удаления выбранной модели нужно выбрать модель заново; автоматической
подмены другой моделью нет.
Конфигурация: `upstreamPins: [{ model: cline-pass/deepseek-v4.1-flash-1017, provider: deepseek }]`.

В 0.7.2 добавлена отдельная модель **DeepSeek V4.1 Flash 1017** из официального
[каталога Cline](https://api.cline.bot/api/v1/ai/cline/recommended-models), проверенного
2026-10-25. Старые ID, выбор сессии, значения по умолчанию и закрепления не меняются.
Возможности изображений, рассуждений, контекста 1M и вывода 384K взяты из
[документации DeepSeek](https://api-docs.deepseek.com/quick_start/pricing/), а не из
измерений ClinePass; бюджет запроса остаётся 65536. Включите модель с `-1017`,
сохраните отдельное закрепление `deepseek` и явно выберите её в потоковой проверке.
Для чата выберите её в самой сессии. Фильтр тарифа может скрыть модель, если её нет
в обнаруженном списке аккаунта. Применение ограничения требует проверки аккаунта;
автоматической замены модели или фоновых запросов нет.

Подробности маршрута показывают только полученные идентификаторы ответа, модели,
канонической модели, resolved provider и отпечаток из метаданных DeepSeek. Они не
заменяют проверку final provider: private-канал не считается `deepseek`. Полный текст
планирования, заголовки и диалог не сохраняются; старые записи не дополняются догадками.
Статистика обычной проверки относится к запрошенной модели, возвращённая показана отдельно.

При включённом плагине ограничение действует для прямых и прокси-вызовов,
вспомогательных запросов, потоковых и обычных проверок. Прямой запрос фиксирует
настройку при подготовке; прокси — при приёме запроса. Повтор на другом аккаунте
сохраняет ограничение провайдера. Другой backend не запрашивается как fallback.
Оба маршрутизатора получают `provider.only` и `providerOptions.gateway.only`;
для `zai`/`z-ai` используется соответствующее написание.

Для `cline-pass/deepseek-v4.1-flash-1017` с закреплением `deepseek` плагин
добавляет `vision` и `implicit-caching` в `providerOptions.gateway.has`, сохраняя
дополнительные условия клиента без дубликатов. Отсутствующее, null или пустое
значение получает оба тега. ID ClinePass, ключ, выбор модели и сохранённая
конфигурация не меняются. Проверка 2026-10-26: только `only` приводил к private,
комбинация — к DeepSeek; модель без суффикса оставалась на private даже с тегами.
Поэтому исправление ограничено этим ID и закреплением. Другие провайдеры и
автоматическая маршрутизация не меняются. Дополнительные условия могут исключить
всех кандидатов.

Потоковая проверка показывает запрошенного и фактического провайдера и делает
реальный запрос. Несовпадение возвращает `UPSTREAM_PIN_MISMATCH`, отсутствие
метаданных — `UPSTREAM_PIN_UNVERIFIED`. Некоторые аккаунты игнорируют ограничение:
HTTP 200 не доказывает его применение. Поздняя ошибка не отменяет уже полученный
вывод и расходы, запрос не повторяется. Попадания в кэш не гарантируются.
Локальные проверки используют установленный DSH и проверяют ошибки маршрутизации.
Короткие текстовые запросы одного реального аккаунта ClinePass подтвердили
комбинацию для 1017 2026-10-26; изображения, большой контекст, списание квоты и
будущая маршрутизация не проверены. Протокол основан на публичных исследованиях
[cline-pass-switcher](https://github.com/munmunjaklin458-afk/cline-pass-switcher)
и [dsh-cline-pass](https://github.com/yhshzh/dsh-cline-pass).

Поле ввода показывает провайдера последнего ответа. В подробностях сессии и
статистике видны запрошенный провайдер, наличие ограничения в запросе, фактически
сообщённый провайдер и результат сравнения, включая ошибки и автоматический режим.
Хранятся последние 100 запросов профиля и попытки аккаунтов, в статистике видны
последние 10 (до 50 по кнопке); ключи и текст
диалога не записываются. Совпадение относится только к этому ответу и не доказывает
будущее применение ограничения. Метка модели показывает лишь настройку.
Записи сессии обновляются при завершении вызова, открытии подробностей и вручную;
данные другой сессии или текущая настройка не заменяют отсутствующее наблюдение.
Старые записи без метаданных помечаются как «не записано». CSV остаётся сводным;
маршруты отдельных запросов доступны в поле `recent` API статистики.

`proxyEnabled` по умолчанию выключен. Прокси слушает только loopback и использует
отдельный секрет в DSH credentials. Маршрут модели важнее ручного выбора аккаунта,
затем привязки сессии и стратегии `least-used` или `round-robin`. Повтор на другом
аккаунте разрешён только до первого вывода модели. Отключение восстанавливает
адрес, аккаунт и исходные параметры повторов и тайм-аутов. Сроки подключения,
первого вывода и JSON — 15 с, простоя потока — 30 с, всего — 300 с;
полный запрос ограничен 32 MiB. Лимиты изображений задаются отдельно.
`historyImageOffload` выключен по умолчанию, `historyImagesToKeep` равен 2.
Выгрузка требует нативного плагина хоста, записывает решение в журнал сессии и
сохраняет исходные вложения. Прокси принимает точные ID из списка моделей плагина;
перед вызовом новой модели добавьте её. Результаты и границы проверки описаны в
[журнале проверки](docs/maintenance/VALIDATION.md).

Файл статистики: `<каталог текущего профиля>/clinepass/stats.json`. Атомарная
замена и блокировка хоста защищают параллельную запись. Итоги по дате, модели и
аккаунту сохраняются; подробности — только для последних 100 запросов. Повтор
прокси не увеличивает число логических запросов. Отсутствующий usage неизвестен.
Итоги запросов относятся к последнему аккаунту; попытки сохраняют фактический
аккаунт. Строки CSV `scope=request|attempt` нельзя складывать как число запросов.
Кэш отделён от обычного ввода, рассуждение уже включено в вывод. Указывается доля
измеренных запросов; задержки — средние, без TTFT для не потоковой проверки.
Ошибка записи видна, но не прерывает модель; новые данные остаются в памяти.
Сброс очищает статистику всего профиля, сохраняя аккаунты и модели; повреждённый
файл сначала архивируется. Старые измерения не восстанавливаются расчётом.

Официальный Cline поддерживает поиск внутри модели ClinePass, но это не подтверждает
отдельный поисковый API для DSH. Адаптер **ClinePass standalone search · experimental**
по умолчанию выключен, реальный канал не проверен. Он использует активный аккаунт и `POST /alpha/web-search` по адресу
`baseUrl`. После включения выберите `clinebot` в настройках поиска хоста.
Другие провайдеры поиска и загрузки сохраняются. Запрос ограничен 10 результатами
(по умолчанию 5). Пустой результат отличается от ошибок HTTP, ключа, формата,
тайм-аута и отмены. Нет скрытого перехода на другой сайт или смены аккаунта.
Отключение и выгрузка снимают регистрацию и отменяют текущие поиски.
Проверены изолированный next и локальная имитация; реальный канал ещё не проверен.

Для DeepSeek Search / Fetch настройте официальный провайдер и ключ DeepSeek в
настройках веб-поиска хоста. Каждый API стоит 5 CNY за 1000 успешных запросов с
результатом; ошибки, пустые результаты и тайм-ауты не оплачиваются. Серверные
вызовы инструментов оплачиваются с 2026-11-01 00:00 по Пекину. Эти расходы не
входят в оценку токенов ClinePass. [Официальные условия](https://api-docs.deepseek.com/zh-cn/guides/search/).

В DSH next `0.2.1-rc.2` отключение плагина отменяет текущие вызовы, закрывает
прокси, удаляет временный ключ и восстанавливает встроенный адаптер моделей.
Конфигурация моделей и аккаунтов сохраняется. Повторное включение и горячее
обновление автоматически синхронизируют адаптер и ключ, сохраняя настройки и
статистику. Эти операции проверены в изолированном CLI Web; Desktop ещё не проверен.

В настройках показаны только запущенная версия и ссылка на репозиторий.
Обновления доступны в **Плагины → ClinePass updates**.
Цель GitHub закреплена за проверенным коммитом этого репозитория. Для локальной
или registry-установки цель выбирается явно; локальное обновление принимает
абсолютный путь к `.tgz`/`.tar.gz`, созданному `npm pack`. Проверку, установку,
блокировку профиля, отмену и результат выполняет хост. Аккаунты, модели и
статистика сохраняются; фоновой установки нет.

Запущенная и установленная версии различаются даже при одинаковом номере.
Одинаковый путь архива или неизвестный Git-коммит не доказывает совпадение кода.
Выполните предложенный перезапуск/обновление страницы и проверьте снова. Архив
читается без распаковки: до 16 MiB сжатых данных, 64 MiB записей и 256 KiB
манифеста. `GET /dsh-clinebot/update` только проверяет цель; установка идёт через
нативное окно, прежняя HTTP-команда установки отвечает 405.

## Разработка

```sh
npm run build:client
npm test
```

`npm test` проверяет соответствие `lib/client.js` исходникам без перезаписи,
проверяет неопределённые имена и запускает тесты. `npm pack` собирает
локальный архив. Без установки с GitHub: `dsh plugin --profile web add ./<файл>.tgz`.
